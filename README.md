# ♟ Шахматы Зла / Chess of Evil

Шахматы с элементом удачи. В начале каждого хода бросаются 2к6 — сумма становится Очками Действий (ОД), которые тратятся на перемещение фигур.

![Build](https://github.com/YOUR_USERNAME/YOUR_REPO/actions/workflows/build.yml/badge.svg)

## Скачать

Перейди во вкладку **[Releases](../../releases)** и скачай последнюю версию:
- `Chess_of_Evil.exe` — для Windows (запускается без установки)
- `Chess_of_Evil_Linux` — для Linux

Или скачай из вкладки **[Actions](../../actions)** → последний успешный запуск → Artifacts.

## Правила

| Фигура | Стоимость хода (ОД) |
|--------|-------------------|
| ♔ Король | 8 |
| ♕ Ферзь | 6 |
| ♖ Ладья | 5 |
| ♗ Слон | 3 |
| ♘ Конь | 3 |
| ♙ Пешка | 1 |

- **Рокировка** — 5 ОД
- **Максимум действий за ход** — 3
- **Бросок 12** — Критическая удача: одна фигура может ходить дважды
- **Бросок 2** — Критическая неудача: −1 ОД
- **Шах** — ход короля стоит все оставшиеся ОД
- **Королевский Гамбит** — когда остался только король, его ход стоит 1 ОД
- **Столкновение Судеб** — когда у обоих только короли, можно воскрешать фигуры (кроме пешек; ферзь — 1 раз)

## Сборка из исходников

```bash
pip install pygame pyinstaller
pyinstaller --onefile --windowed --name Chess_of_Evil main.py
# .exe появится в папке dist/
```
